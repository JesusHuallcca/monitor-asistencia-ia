    Evaluación sin mirar el futuro

    No se comparten estudiantes entre particiones. Los datos de prueba son posteriores a la validación, y esta es posterior al entrenamiento. La evaluación mide generalización a nuevas cohortes sintéticas.

    Las notas se incorporan solo cuando su fecha de disponibilidad es anterior a la sesión objetivo. Los identificadores y la etiqueta asistira nunca son entradas.

    Conceptos para la sustentación

    Neurona. Combina entradas mediante pesos y un sesgo, y aplica una activación.

    Capas ocultas. Aprenden combinaciones de las variables históricas; no son categorías psicológicas.

    Época. Un recorrido completo por los ejemplos de entrenamiento.

    Activación. ReLU permite relaciones no lineales; sigmoide produce un valor entre 0 y 1.

    Forward propagation. Calcula una salida a partir de entradas y pesos actuales.

    Backpropagation. Propaga el error para calcular cómo modificar cada peso.
